Place contestant images here as WebP files named exactly after the contestant with ".webp" extension.

Examples:

- Amaya.webp
- Bryan.webp
- Nic.webp

Image requirements:

- Dimensions: 667x1000 (as provided)
- Format: WebP
- Filenames must match the contestant names used in the UI dropdown.

The app will load images from `/islanders/<Name>.webp`.
